# حل مشكلة EBUSY في Node.js

## الملفات المتوفرة:
- `fix-ebusy-issue.bat` - سكربت Windows Batch
- `fix-ebusy-issue.ps1` - سكربت PowerShell

## طريقة الاستخدام:

### باستخدام Batch Script:
```cmd
fix-ebusy-issue.bat
```

### باستخدام PowerShell:
```powershell
.\fix-ebusy-issue.ps1
```

## ما يقوم به السكربت:

1. **إيقاف عمليات Node.js**: يوقف جميع عمليات node.exe قيد التشغيل
2. **حذف الملفات المؤقتة**: يحذف مجلدات `.next` و `node_modules`
3. **تنظيف npm cache**: ينظف ذاكرة التخزين المؤقت
4. **إعادة التثبيت**: يعيد تثبيت الحزم باستخدام `--legacy-peer-deps`
5. **تشغيل الخادم**: يبدأ تشغيل `npm run dev`

## نصائح إضافية:

### إذا استمرت المشكلة:
1. أضف المجلد إلى استثناءات Windows Defender
2. تأكد من عدم تشغيل محرر النصوص على الملفات
3. أعد تشغيل الكمبيوتر إذا لزم الأمر

### للمشاريع الكبيرة:
استخدم WSL2 للحصول على بيئة تطوير أكثر استقراراً.
